# wellington-araujo-dev
Portfólio profissional em React focado na apresentação de sistemas reais desenvolvidos para instituições públicas e privadas. O projeto destaca estudos de caso detalhados, arquitetura modular, componentes reutilizáveis e suporte bilíngue (PT/EN), com foco em narrativa técnica, UX e apresentação de impacto de software.
